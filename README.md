# FirstEscape

Unreal Engine 5를 처음 배우면서 제작하고 있는 1인칭 게임 프로젝트입니다.

단순히 튜토리얼을 따라 만드는 것보다 직접 작은 게임을 완성해보면서
Unreal Engine의 기본 기능과 게임 개발 과정을 익히는 것을 목표로 하고 있습니다.

## 🎯 프로젝트 목표

- Unreal Engine 5의 기본적인 사용법 익히기
- 1인칭 게임의 기본 구조 이해
- 플레이어 상호작용 시스템 구현
- UI, 아이템, 맵 제작 등 다양한 기능 학습
- 작은 규모라도 처음부터 끝까지 플레이 가능한 게임 완성하기

## 🎮 현재 구현된 기능

### 문 상호작용
- 플레이어가 일정 거리 안에 들어오면 상호작용 가능
- E키를 이용해 문 열기
- E키를 다시 눌러 문 닫기
- 상호작용 범위를 벗어나면 문 조작 불가능

### 입력 시스템
- Unreal Engine Enhanced Input 사용
- `IA_Interact`를 생성하여 E키 상호작용 구현

## 🛠 사용 기술

- Unreal Engine 5
- Blueprint
- Enhanced Input
- Git / GitHub

## 📚 학습 내용

이 프로젝트를 진행하면서 다음 내용을 공부하고 있습니다.

- Actor와 Component의 개념
- Transform (Location / Rotation / Scale)
- Blueprint Event Graph
- Boolean 변수
- Branch를 이용한 조건 처리
- Collision과 Overlap Event
- Blueprint 간 데이터 전달
- Enhanced Input
- Git을 이용한 프로젝트 버전 관리

## 🚧 앞으로 구현할 기능

- 열쇠 및 아이템 획득
- 잠긴 문
- 상호작용 안내 UI
- 인벤토리
- 체력 시스템과 체력 UI
- 1인칭 아이템 표시
- 실제 플레이용 맵 제작
- 조명 및 사운드
- 게임 클리어 시스템

## 📌 개발 목적

게임 개발과 Unreal Engine을 공부하기 위한 개인 학습 프로젝트입니다.

기능을 하나씩 직접 구현하면서 게임이 어떤 구조로 만들어지는지 이해하고,
최종적으로는 혼자서 작은 3D 게임을 제작할 수 있는 것을 목표로 하고 있습니다.
